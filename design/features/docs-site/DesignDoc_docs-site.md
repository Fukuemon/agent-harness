# 文書のサイト

## Overview

パッケージ docs-site は、リポジトリの文書、カタログ、図を 1 つのサイトに並べ、pull request ごとにプレビューを出し、取り込んだら公開する構成を持つ。全体像は [agent-harness Design Doc](../../DesignDoc.md) にある。

## Scope

- 持つもの: サイトに並べるものの組み立て、プレビューと公開のワークフロー、アクセスの保護の手順、モックの埋め込みとトークンの当て方。
- 持たないもの: 文書の中身と形（docs と screens が持つ）。カタログの中身（design-system と利用者が持つ）。

## Design

### 組み立て

`docs_site.parts` に並べたもの（文書のディレクトリ、カタログのビルドの出力、図の出力）を、1 つの出力のディレクトリのサブパスに並べる。文書のサイトのジェネレーターの設定は、雛形から利用者が選んで写す。

### プレビューと公開

pull request ごとにプレビューを出し、URL を pull request のコメントに書き、更新のたびに同じコメントを直す。fork と依存の更新の pull request では出さない。既定のブランチへ取り込んだら公開する。  
公開先の秘密の値は CI の secrets に置き、権限は 1 つの公開先の編集だけに絞る。

### 保護

公開先の単位でアクセスの保護を掛け、プレビューも同じ保護の内側に置く。保護されていることを、認証のない要求がリダイレクトされることで確かめる。

## Interface

- 読むキー: `docs_site.parts`（並べるもののパスとサブパス）、`docs_site.tokens_css`（サイトの色に当てるトークンの CSS）。
- 写す雛形: 組み立てのスクリプト、プレビューと公開のワークフロー、保護の手順書、ジェネレーターと公開先ごとの設定（`references/` の下から選ぶ）。
