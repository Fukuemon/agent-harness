# E2E

## Overview

パッケージ e2e は、E2E のテストの書き方の判断と、テストと録画を支える kit のコードを持つ。全体像は [agent-harness Design Doc](../../DesignDoc.md) にある。  
kit はブラウザのテストのツールに依るコードなので、スキルとは別に npm のレジストリで配る。

## Scope

- 持つもの: E2E のテストの層、名前、待ち方、確かめ方の判断（スキル write-e2e-test）。kit のコード（録画、エビデンスの名前と置き場、ログインの保存）。テストの書き方を止める lint の規則。
- 持たないもの: プロダクトの値（画面の ID の形、ログインの手順、環境の URL）。観点の設計とエビデンスの添付（verification が持つ）。

## Design

### kit

kit は 3 つの部分を持つ。プロダクトの値は引数と設定で受け、kit の中に業務の語を持たない。

| 部分 | 持つもの |
| --- | --- |
| recording | 録画の開始と終了、字幕とカーソルの重ね、操作と確認の段の記録 |
| evidence | シナリオと変種（改修の前と後）、エビデンスの名前と置き場 |
| auth | ログインの状態の保存と再利用、ワンタイムのコードの読み取り |

### lint の規則

層ごとに使ってよい確認、画面の遷移の書き方、要素の指し方、固定の待ちの禁止を止める。プロダクトの値（画面の ID の形など）は規則の options で受ける。

### テストの分け方

テストのプロジェクトを、準備、E2E、エビデンスの 3 つに分ける。CI は E2E だけを流し、エビデンスは pull request を作るときに手元で撮る。

## Interface

- npm のパッケージ: kit と lint の規則。名前と公開の仕方は ADR-0024 が決める。
- 読むキー: `e2e.dir`（E2E のテストのディレクトリ）。
- 写す雛形: テストのプロジェクトの分け方の設定、lint の設定、エビデンスの薄い層の雛形。
