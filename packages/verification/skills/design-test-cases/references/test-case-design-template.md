### 呼び出しの tree

<!-- 変更を対象にしないときは text のブロックにし、行頭の +、- を付けない -->

行番号は {{変更後の SHA}} のもの。`-` は変更の前にあって消えた節、`+` は変更の後で足した節。

```diff
  {{ファイル}}  {{対象処理}}
  ├── {{入力処理}}                          :{{行}}
  ├── {{分岐・候補取得}}
- │   ├── {{変更の前の分岐A}}
+ │   ├── {{変更の後の分岐A}}                :{{行}}
  │   └── {{分岐B}}
+ ├── {{足した処理}}                        :{{行}}
  ├── {{合流・集約・状態更新}}
  └── {{返却・外部作用}}
  呼び出し元
  └── {{変えた関数を共有する呼び出し元}}  {{ファイル}}:{{行}}  [影響]
```

### 入力から結果までの flowchart

左が変更の前、右が変更の後。灰の破線は消えた節、緑は足した節、赤は前後で結果が違う節。

```mermaid
flowchart LR
  subgraph before[変更の前]
    direction TB
    b_in["{{入力}}"] --> b_cond{"{{入力の条件}}"}
    b_cond -->|{{条件A}}| b_a["{{結果}}"]
    b_cond -->|{{条件B}}| b_old["{{消えた処理}}"]:::removed --> b_b["{{結果}}"]:::diff
  end
  subgraph after[変更の後]
    direction TB
    a_in["{{入力}}"] --> a_cond{"{{入力の条件}}"}
    a_cond -->|{{条件A}}| a_a["{{結果}}"]
    a_cond -->|{{条件B}}| a_new["{{足した処理}}"]:::added --> a_b["{{結果}}"]:::diff
  end
  before ~~~ after
  classDef removed stroke:#888,stroke-dasharray:4 3,color:#888
  classDef added stroke:#2a2,stroke-width:2px
  classDef diff stroke:#d32f2f,stroke-width:3px
```
