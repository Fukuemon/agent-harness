## 画面を作るときの原則

<!-- 画面のコードで守る規則を箇条書きにする。次の 6 つを出発点にし、プロダクトに合わせて直す -->

- 色、文字、角丸、影は、テーマの段のユーティリティだけで書く。色の値と基本の段の名前を、画面のコードに直に書かない。
- 状態を色だけで伝えない。エラーと注意には、文と印を色と一緒に出す。
- 14px より小さい文字を使わない。本文と操作の文字は 16px にし、14px は補足だけに使う。
- 主のボタンは、1 つの画面かダイアログに 1 つまでにする。
- フォーカスの表示は 1 つのユーティリティだけを使い、コンポーネントごとに色や太さを変えない。
- 押せる領域は 44×44 CSS px 以上にする。WCAG 2.2 の AA（2.5.8）の 24×24 より厳しい、AAA（2.5.5）の値を選んでいる。見た目を小さくするときは、見た目の外に押せる領域を広げる。
